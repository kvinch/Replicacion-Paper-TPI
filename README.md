# Réplica en Python de Grigorescu, Alistar y Lincaru (2025)

## Descripción

Este proyecto reproduce en Python la metodología propuesta por Grigorescu, Alistar y Lincaru (2025), cuyo estudio analiza la vulnerabilidad de los jóvenes que ni estudian ni trabajan (NEET o *ninis*) en 28 países europeos.

El artículo examina la relación entre la tasa de jóvenes NEET y 24 indicadores relacionados con el uso de internet y las habilidades digitales. La investigación original fue desarrollada utilizando **SPSS y ArcGIS**. Esta réplica busca reproducir los mismos procedimientos metodológicos utilizando **Python**.

## Referencia

> Grigorescu, A., Alistar, T. V., & Lincaru, C. (2025). Digital skills, ethics, and integrity: The impact of risky internet use, a multivariate and spatial approach to understanding NEET vulnerability. *Systems, 13*(8), 649. https://doi.org/10.3390/systems13080649

## Requisitos

- Python 3.10 o superior.
